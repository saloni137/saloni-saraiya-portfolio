# Saloni Saraiya — Portfolio

A personal portfolio about the craft of building full-stack and AI products. Designed as a dark systems notebook: black, white and gray surfaces, orange typography, editorial typography, original diagrams and a scroll-driven gallery.

Built with **Astro, TypeScript, GSAP and plain CSS**. All pages are generated as static HTML. No database, API keys or runtime server is required.

## Run locally

Use Node.js **22.19+** (or Node 24).

```sh
npm ci
npm run dev
```

Open the local URL printed by Astro, usually `http://localhost:4321`.

```sh
npm run build  # Type-check and generate dist/
npm test       # Verify the built routes, internal links and metadata
npm run preview
```

## Deploy to Vercel

[Import this repository into Vercel](https://vercel.com/new)

1. Sign in and import `saloni137/saloni-saraiya-portfolio` from GitHub.
2. Keep the root directory as the repository root. Vercel detects Astro.
3. Build command: `npm run build`. Output directory: `dist`.
4. Deploy. Future pushes to `main` trigger a new deployment.

The included `vercel.json` supplies the framework and build settings. No Astro server adapter is needed for this static site.

For a custom domain, set the optional environment variable `SITE_URL` to its full HTTPS URL, such as `https://your-domain.com`, then redeploy. Otherwise the build uses Vercel’s production project URL for canonical URLs, social metadata and the sitemap.

The résumé has a **Print / Save PDF** control. The downloadable document is generated by the browser from the current page, so it stays aligned with the website.

## Motion and accessibility

- A pinned horizontal work gallery on spacious desktop screens; a vertical gallery on mobile and with reduced motion.
- A name-first hero with a typewriter role line, scroll-linked layers, text emphasis and restrained section reveals.
- System motion preferences plus an explicit **Reduce motion** control in the footer.
- Semantic navigation, a skip link, visible keyboard focus and keyboard access to every gallery card.
- Content remains available when JavaScript is disabled.
- Self-hosted fonts and no analytics or tracking scripts.
- A consistent dark screen theme, with a separate light palette for the printed résumé.

## Content boundaries

Case studies describe personal contributions and engineering decisions. Conceptual diagrams are original illustrations, not product screenshots. The performance example labels the specific benchmark measured; it is not a claim about whole-application speed.

The confidential freelance project is deliberately anonymized. Its client name, product identifiers, screenshots, URLs, source code and internal implementation details are not included. Private research, source documents and interview-preparation notes belong outside this repository.

This repository contains portfolio presentation code only. It does not include code from the products described.
